{# How routing works #}
How Routing Works
  • Each step the LLM receives the full message history + JSON schema for all enabled tools, and autonomously chooses the next call.
  • {{ 'Max steps (currently {{ claw_config.max_steps }}) is a safety limit, not a controller — the LLM should call finalize on its own to end the loop.' }}
  • Disabling a capability on the Skills page removes its tool schema from the next loop's function list — the LLM can no longer call it.
  • The ask_user tool lets the LLM pause mid-loop and ask you a question in the chat window; your reply is sent back as a tool result.

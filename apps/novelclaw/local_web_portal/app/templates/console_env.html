About "vector similarity" and dynamic memory Dynamic memory IS the vector database (Chroma). When Claw calls retrieve_context, it runs a similarity search in Chroma to find the most relevant memory entries to inject. This is not extra complexity — it is how dynamic memory works. MEMORY_ONLY_MODE=1 (default) means only dynamic memory is used; external static RAG is disabled.

Workflow

From fuzzy premise to formal run

  1. Start with a rough premise You do not need a perfect brief. Start with genre, characters, and tension.
  2. Refine across multiple rounds Use follow-up rounds to clarify arc, POV, emotional curve, and world rules.
  3. Confirm only when readiness is high That gives the real generation run a cleaner brief and fewer revisions.
